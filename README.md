# UlanziDeckSwift

一个面向 Ulanzi Deck H200 的非官方 macOS 控制应用原型。

## 功能
- 数字
    - 计数器
- 访达
    - 打开文件夹
    - 打开文件
    - 连接SMB
- 页面
    - 功能夹
    - 上一页
    - 下一页
- 网站
    - 打开网页
    - Sub2API 中转站渠道剩余并发
    - Codex 剩余额度和周期
- 游戏
    - 原神（通过米游社查询日常、体力状态）
    - 崩坏：星穹铁道（日常、体力状态）
    - 绝区零（日常、体力状态）
